# Backend Lab

A practical backend lab for learning, organizing, and mastering backend engineering knowledge.

백엔드 개발자가 알아야 할 개념, 실무 문제 해결 패턴, 기술 질문 대응, AI 활용 방식을 정리하는 기술 위키입니다.

## Topics

- Java / Kotlin
- Spring Boot
- JPA
- Database
- Redis / Cache
- Network / OS
- Performance
- Transaction
- Concurrency / Idempotency / Lock
- Batch Processing
- Security / Authentication / Authorization
- Architecture
- Kubernetes / CI/CD
- Observability
- Testing
- AI for Backend Engineers

## Writing Principles

- 개념은 실무 문제와 이어서 정리한다.
- 장점만 쓰지 않고 한계와 깨지는 곳을 같이 쓴다.
- 외운 지식이 아니라 말로 설명할 수 있는 지식으로 만든다.
- 회사 내부 정보, 민감 정보, 운영 로그 원문은 넣지 않는다.
- 사례는 공개해도 되게 일반화해서 쓴다.
- AI 답변은 그대로 믿지 않고 검증한다.

## Directory Guide

| Directory | Purpose |
|---|---|
| `00-home` | 전체 인덱스, 학습 원칙, 숙련도 관리 |
| `01-core` | Java, Kotlin, Spring, JPA, DB, Redis, Network, OS 기본기 |
| `02-practical-backend` | 성능, 트랜잭션, 동시성, 배치, 보안, 아키텍처, 관측성, Kubernetes, CI/CD |
| `03-work-cases` | 직접 겪은 문제를 일반화한 실무 사례 |
| `04-design-cases` | 설계 사례와 기술 질문 모음 |
| `05-ai-workflows` | AI 활용 프롬프트와 개발 루틴 |
| `99-archive` | 오래된 문서 보관 |
| `_templates` | 문서 템플릿 |
| `_assets` | 이미지, 다이어그램 등 첨부 파일 |
| `_private` | Git에 올리지 않는 개인/회사 경험 원본 메모 |
